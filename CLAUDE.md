# LRC Solutions — Videos

## Marca (leer siempre)

Todo video, post o pieza gráfica de este repo usa la marca de LRC IT Solutions definida en `brand/frame.md` (importado abajo). Es la fuente de verdad: colores, tipografía, logo, componentes y reglas.

- Fondos de Instagram: `brand/backgrounds/fondo-azul.jpg` (portadas/cierres, texto blanco) y `brand/backgrounds/fondo-claro.jpg` (contenido, texto ink, acento azul).
- Logo: `brand/logo/lrc-mark.svg` · Fuentes: `brand/fonts/` · Muestra visual: `brand/brand-board.png`.
- En un proyecto HyperFrames nuevo: copiar `brand/frame.md` como `frame.md` del proyecto y `brand/` como `assets/brand/`.
